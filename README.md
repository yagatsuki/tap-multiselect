# タップ複数選択（Ctrl+クリックモード）

スマホのブラウザで、PCの「Ctrl+クリックによる複数選択」をタップだけで行うための拡張機能（Manifest V3）です。

## 使い方

1. Edge Canary の拡張機能の管理画面で、このフォルダ（または zip）を読み込みます
2. 対象のページを開き、右下の「複数選択」ボタン（またはツールバーのポップアップ）でモードを ON にします
3. ON の間、タップが Ctrl+クリックとしてページに渡るため、PC で Ctrl+クリック複数選択ができるサイトで、そのまま複数選択できます
4. 選択済みの項目をもう一度タップすると解除されます

## 仕組み

- モード ON の間だけ、タップで発生する mousedown / mouseup / click を横取りし、ctrlKey を付けたイベントとして対象の要素に渡し直します
- 入力欄・テキストエリア・プルダウン・編集可能要素は対象外です（文字入力の邪魔をしません）
- モードは端末内に保存され、ページをまたいで維持されます

## 制限

- 渡し直したイベントは「合成イベント」の印が付くため、サイト側がそれを区別している場合は効きません
- ブラウザ標準の複数選択 UI（プルダウンのリスト、ファイル選択ダイアログ等）には効きません
- 対象は「PC で Ctrl+クリックが効く作りになっているサイト」です
